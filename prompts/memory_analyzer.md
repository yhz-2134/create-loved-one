# 记忆分析 Prompt

## 任务

你将收到用户提供的关于已故亲人的原材料（照片、聊天记录、文字记录、口述回忆等）。
从中提取关于 **{name}** 的记忆片段和情感连接，用于构建 Memory。

**原则：只提取有依据的内容，没有就标注"原材料不足"。**

---

## 提取维度

### 1. 共同经历

从用户的表达中提取与亲人共同度过的重要事件：
- 家庭聚会和节日
- 旅行和冒险
- 重要的人生里程碑
- 日常的温馨时刻

```
输出格式：
重要事件：[按时间顺序列出]
旅行和冒险：[列表]
家庭聚会：[列表]
日常温馨时刻：[列表]
```

### 2. 标志性特征

提取亲人的独特特征：
- 外貌特征（身高、体型、面容特点）
- 声音特点（音色、语速、语调）
- 习惯性动作（手势、表情、坐姿等）
- 个人习惯（生活习惯、爱好、口头禅）

```
输出格式：
外貌特征：[描述]
声音特点：[描述]
习惯性动作：[列表]
个人习惯：[列表]
```

### 3. 价值观与信念

提取亲人的人生态度和信念：
- 对家庭的态度
- 对工作的态度
- 对生活的信念
- 教育理念
- 人生格言或口头禅

```
输出格式：
家庭观：[描述]
工作观：[描述]
生活信念：[描述]
教育理念：[描述]
人生格言：[列表]
```

### 4. 情感连接

提取用户与亲人之间的情感连接：
- 表达爱的方式
- 特殊的昵称或称呼
- 情感互动模式
- 彼此之间的特殊纽带

```
输出格式：
表达爱的方式：[描述]
特殊昵称：[列表]
情感互动模式：[描述]
特殊纽带：[描述]
```

### 5. 时间线

构建亲人的重要事件时间线：
- 出生和成长
- 重要的人生事件
- 与用户相关的重要时刻
- 去世前后的情况

```
输出格式：
| 时间 | 事件 | 意义 |
|------|------|------|
| {date} | {event} | {significance} |
| ... | ... | ... |
```

### 6. 未完成的心愿

提取用户提到的未完成心愿或遗憾：
- 未实现的目标
- 未说出口的话
- 未完成的计划
- 未了的情感

```
输出格式：
未实现的目标：[列表]
未说出口的话：[列表]
未完成的计划：[列表]
未了的情感：[描述]
```

---

## 输出要求

- 语言：中文
- 没有信息的维度：标注 `（原材料不足）`
- 有原文依据的结论：引用原话（加引号）
- 避免过度推断，保持客观真实
- 输出结果直接用于生成 memory.md，要求具体可感，不要写抽象形容词
- 保持温和、尊重的语气，避免使用可能触发痛苦回忆的词汇
