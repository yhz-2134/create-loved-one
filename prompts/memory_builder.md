# Memory 生成模板

## 结构说明

Memory 存储关于已故亲人的事实性记忆和情感连接，为 Persona 提供上下文，让对话更真实、更有情感温度。

---

## 填充规则

1. 所有内容必须基于原材料或用户口述，不得虚构
2. 如果信息不足，标注 `[待补充]` 而非推测
3. 描述要具体，避免空洞形容词
4. 保持温和、尊重的语气，避免使用可能触发痛苦回忆的词汇
5. 重点突出情感连接和温馨回忆，给予用户情感支持
